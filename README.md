#### Python学习第一天感悟（第1、2章）

今天是我学习Python的第一天，跟着课本学习了第一章和第二章的内容，收获很多。之前我只听说过Python很简单好用，今天才真正理解程序设计的基本思路。



第一章我学习了程序设计基本方法，了解了计算机、编程语言的概念，知道Python是一种解释型语言，区分了编译和解释两种执行方式。我记住了IPO方法：输入（Input）、处理（Process）、输出（Output），这是写程序最基础的思路。同时我认识了算法、控制结构和计算思维，明白写代码本质是把问题变成计算机可以理解的步骤。我也学会了Python的两种运行方式：交互式运行和文件式运行，知道IDLE是Python自带的开发环境。



第二章学习Python基础语法元素，这是写代码的核心。我学会了注释、变量、保留字、赋值语句、分支和循环语句。掌握了`input()`、`eval()`、`print()`这三个最常用输入输出函数。还了解了三种Python编程模式：过程式、生态式、对象式。最后学习了turtle绘图库，学会三种导入库的写法：`import`、`from ... import`、`import ... as`。



在课后我也手敲了课本上的两个实例，一个是温度转换，一个是蟒蛇绘制。敲代码的时候我发现，标点、缩进、大小写都不能写错，一点点小错误程序就跑不起来，写代码需要非常细心。

Python入门没有想象中那么难，但是需要多动手敲代码、多调试。接下来我会继续练习，熟悉语法，多写实例，慢慢锻炼自己的编程思维。
